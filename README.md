
# Craic Mods & Gaming — Official Releases

Welcome to the official download repository for Craic Mods & Gaming.

## About

We create free, approachable tools and tutorials to help gamers, parents, and families install and manage private dedicated game servers.

Our focus is on making gaming technology easier to understand and more affordable.

## Available Projects

### Conan Exiles Dedicated Server Tools

Our Conan Exiles toolkit includes:

- Windows dedicated server installer
- Interactive server configuration manager
- Configuration backup and recovery features
- Optional online version checking

Downloads will appear under the Releases section once testing and packaging are complete.

## Download Instructions

1. Open the Releases section of this repository.
2. Select the latest approved release.
3. Download the attached ZIP package.
4. Read the included README before running any scripts.
